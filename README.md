GameSpace
========================================
GameSpace is an advanced Android utility designed to optimize the gaming experience by managing system performance and notifications through a centralized interface.

Features:
=====
 * FPS counter
 * Network optimization
 * ModernUI
 * Performance profiles
 * and more!

How to use:
=====

Just call the app in the device.mk devicecommon.mk common.mk file

    PRODUCT_PACKAGES += \
       GameSpace

and include the sepolicy

    include packages/apps/GameSpace/sepolicy/SEPolicy.mk
